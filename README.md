# 🌱 Hortalize

> **Hortalize** — Aprenda a cultivar, mesmo em pequenos espaços.

## 📖 Sobre o projeto

O **Hortalize** é um projeto desenvolvido como parte de uma **atividade extensionista do curso de Engenharia da Computação da UNINTER**.

O projeto tem como propósito utilizar a tecnologia para gerar um impacto positivo na sociedade, desenvolvendo uma solução que possa compartilhar conhecimento e ajudar as pessoas no dia a dia.

Nesse contexto, o Hortalize foi desenvolvido como uma espécie de **blog educativo sobre jardinagem**, com o objetivo de ajudar pessoas a aprenderem a cultivar plantas, hortaliças e outros tipos de vegetação em suas próprias casas ou apartamentos.

A proposta é tornar a jardinagem mais acessível, oferecendo informações de maneira simples e didática, mesmo para pessoas que nunca tiveram experiência com cultivo.

## 🎯 Objetivo

O principal objetivo do Hortalize é **incentivar e facilitar o aprendizado sobre jardinagem doméstica**.

A plataforma busca ajudar os usuários a:

- 🌱 Aprender os conceitos básicos de jardinagem;
- 🏠 Cultivar plantas em casas e apartamentos;
- 🌿 Conhecer diferentes tipos de plantas e seus cuidados;
- 💧 Entender necessidades como rega, iluminação e adubação;
- 🪴 Aproveitar pequenos espaços para criar áreas de cultivo;
- 📚 Encontrar informações de forma simples e acessível.

## 💡 A ideia

Para muitas pessoas, começar uma horta ou cuidar de plantas pode parecer complicado. Dúvidas sobre qual planta escolher, quanto regar, qual ambiente utilizar ou como preparar o solo podem acabar desmotivando quem deseja começar.

O **Hortalize** busca ajudar justamente nesse primeiro passo.

Por meio de conteúdos educativos, a plataforma apresenta informações que podem auxiliar tanto quem está começando na jardinagem quanto quem já possui alguma experiência.

A ideia é mostrar que **não é necessário possuir um grande quintal ou conhecimentos avançados para começar a cultivar**.

## 🌍 Impacto social

Como projeto de extensão universitária, o Hortalize busca aplicar os conhecimentos adquiridos durante a graduação em uma solução que possa beneficiar a comunidade.

Acreditamos que a tecnologia pode ser utilizada não apenas para desenvolver sistemas, mas também para **compartilhar conhecimento e contribuir para a sociedade**.

O Hortalize utiliza a web como meio de disseminação de informações sobre jardinagem, buscando incentivar o cultivo de plantas e tornar esse conhecimento mais acessível.

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando tecnologias fundamentais para o desenvolvimento web:

| Tecnologia | Utilização |
|------------|------------|
| **HTML5** | Estrutura e organização das páginas |
| **CSS3** | Estilização, layout e responsividade |
| **JavaScript** | Interatividade e funcionalidades da aplicação |

## 🌐 Hospedagem e escalabilidade

Atualmente, o Hortalize é uma aplicação web estática desenvolvida com **HTML, CSS e JavaScript**, hospedada utilizando o **GitHub Pages**.

Essa abordagem foi escolhida por sua simplicidade e por atender às necessidades atuais do projeto, permitindo que a aplicação seja disponibilizada na web sem a necessidade de um servidor ou infraestrutura adicional.

### 🚀 Possível evolução

Embora a implementação atual seja adequada para a proposta acadêmica do projeto, uma futura expansão do Hortalize poderia exigir uma estrutura mais robusta.

Caso o projeto fosse **escalado para uma aplicação de produção com grande quantidade de conteúdo e usuários**, uma possibilidade seria utilizar uma plataforma de gerenciamento de conteúdo (**CMS**), como o **WordPress**, ou alguma solução semelhante.

Isso permitiria, por exemplo:

- 📝 Facilitar a criação e gerenciamento de artigos;
- 👥 Permitir diferentes níveis de acesso para administradores e autores;
- 🗂️ Organizar uma quantidade maior de conteúdos;
- 🔎 Implementar recursos de busca e categorização;
- 💬 Adicionar novas formas de interação com os usuários;
- 📈 Facilitar a manutenção e evolução da plataforma.

Essa possibilidade faz parte da visão de evolução do projeto e **não representa a arquitetura utilizada atualmente**.
